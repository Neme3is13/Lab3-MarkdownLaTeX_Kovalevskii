# Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

#### Markdown — это облегчённый язык разметки, который позволяет форматировать обычный текст с помощью простых символов. Вместо сложных HTML-тегов здесь используются привычные знаки: решётки для заголовков, звёздочки для выделения текста, дефисы для списков и так далее

#### Markdown применяют для простого форматирования текста — в документации, заметках, постах, на сайтах и в чатах.

#### Markdown нужен разработчикам, чтобы быстро и удобно оформлять текст без HTML‑тегов
